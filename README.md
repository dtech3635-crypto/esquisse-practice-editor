# エスキス練習エディター

一級建築士試験の設計製図(エスキス)対策として、ホテル基準階の平面計画を練習できるブラウザアプリです。課題を選んで客室・廊下・階段・エレベーターなどを配置すると、要求室・動線・二方向避難・外構条件を自動採点します。

🔗 **公開ページ**: https://dtech3635-crypto.github.io/esquisse-practice-editor/

## 主な機能

- **課題条件**: ビジネスホテル・シティホテル・リゾートホテル・ラグジュアリーホテルなど、客室タイプの組み合わせが異なる30パターンの基準階課題(矩形21パターン・L型9パターン)
- **ゾーニング配置**: 客室(シングル〜スイート11タイプ)、廊下、管理用/利用者階段、EV(管理用/利用者用)、リネン室、空調室などをグリッド上に配置
- **自動採点**: 要求室・面積(40点)、廊下・接続(25点)、二方向避難(25点)、外構・接道(10点)の100点満点で判定
- **案の保存・比較**: 複数案を保存して得点を比較
- **課題の自動生成**: 既存課題をベースに客室構成とグリッドをランダムに変化させて新しい課題を生成

## 使い方(ローカルで動かす場合)

Node.js 18以降が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:4173 を開いてください。

### 基本操作

1. 「課題条件」から練習したい基準階パターンを選び、「この課題を開始」を押す
2. 左側の「室構成」から部屋種別を選び、グリッドをクリックして配置(ドラッグで移動、右クリックでコピー・削除)
3. 「採点する」で自動採点結果を確認
4. 「案を保存」で現在の配置を保存し、「案を比較」で複数案のスコアを見比べる

## 技術構成

素の HTML/CSS/JavaScript(フレームワーク不使用)で作られた静的サイトです。`server.mjs` はローカル動作確認用の簡易サーバーで、GitHub Pages などの静的ホスティングにそのままデプロイできます。

- `index.html` / `styles.css` — 画面のベース
- `app.js` — グリッド・配置・図形描画のコアロジック
- `learning.js` — 課題データ・自動採点ロジック
- `staging.js` — 複数選択・仮置き・コピー&ペーストなどの操作補助
